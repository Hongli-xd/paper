## 主方案速览

**论点（唯一不可协商的架构主张）**

> 自回归模型无法在**条件于后文**的前提下修改前文；扩散语言模型可以。

智能体生成 10 步计划，第 3 步失败。AR 只能：留着错的 / 丢弃第 4–10 步重来 / 从上下文删掉第 3 步。它**做不到**把第 3 步改得刚好服务于第 4–10 步——生成第 3 步时后文在它的条件里不存在。这是因果注意力的定义决定的。

⚠️ 不要写成"AR 无法收回说出口的话"——那是错的，可以编辑上下文，审稿人一句话能打掉。

**为什么现在做**

|---|---|
| dLLM 在 ALFWorld 当前 SOTA | **10.4%**（AR 是 60–90%），头顶 ~70 分 |
| dLLM 多轮工具调用 | **0 个样例成功** |

**机制（为什么必须先解决它）**

重试循环 = mean-field 因子化 + 置信度提交 → 每步在每个位置选边缘众数，联合塌到单一动作。升温只加逐位置独立噪声 → 不连贯。**夹在"永远重复"与"胡言乱语"之间。**

→ 重新掩码后若还吐同一个动作，修复能力等于不存在。**坍缩就是锁住论点的那把锁。**

**方法**：关键位置优先提交 · 跨度级历史排斥 · 循环触发重掩码。全部 logits 后处理，不碰权重。

**核心实验**：受控错误注入 + 五条件对照（含 AR-reflect 强基线与 AR-oracle-truncate 上界）。
决定性结果：`dLLM-revise ≈ AR-oracle-truncate > AR-reflect`，且修复代价显著低于 `AR-regen`。

**止损点**：第 1 周诊断实验验证机制假设，不成立就换题。

**三条红线**：核心实验只用 bf16 不用 4bit · 一卡一模型不切分 · AR 基线必须给足反思重规划。
